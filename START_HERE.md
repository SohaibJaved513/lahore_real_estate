# Start Here

1. Open a terminal in the project folder.
2. Create and activate a virtual environment.
3. Run `pip install -r requirements.txt`.
4. Run `python run_pipeline.py` to regenerate the complete real-data results.
5. Run `python app.py` and open `http://127.0.0.1:5000`.
6. Read `results/REPORT.md` and `docs/INTERVIEW_PREPARATION.md` before submission.

The required dataset is already included at `data/raw/lahore_house_listings_zameen.csv`.
